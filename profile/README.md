## Inside Dips

Dips is a local Windows structural geology app with a named dips desk, a short stereo list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside planes you already own and holds only the set that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra stereonets wait for their own title. Dips starts with a local profile and does not need a complex account system.
